Теперь можно начать обращение, не открывая сначала историю. Удерживайте значок Pole parkla и выберите «Новый репорт»: приложение откроет камеру для нового обращения.

Ярлык также можно перетащить на главный экран. Ранее сохранённые обращения остаются в истории.
